# 云迹先知（CloudTrace）微信小程序 MVP

云迹先知面向“未来一小时强回波影响判断”：展示区域级可能性、回波对象和可追溯的判断依据。当前页面使用固定合成样本演示这些数据的组织方式。

## 目标场景

- **气象播报**：快速组织未来一小时趋势和重点区域
- **机场与交通调度**：关注跑道、进离港窗口和交通走廊
- **城市应急与防汛**：提前安排积水点、泵站和巡查力量
- **大型活动与园区防灾**：评估人群、户外作业和设施风险

## 页面与交互

- **对话 Tab**：首页提供基于固定样本的本地演示问答、快捷问题，以及保存在当前设备的多条会话记录。目前没有 AI 服务。
- **研判 Tab**：选择气象播报、机场调度、城市防汛或活动园区场景，查看重点区域和预测时点；场景共用同一份概率样本。
- **依据 Tab**：查看当前区域的结论、关联回波、卫星、移动趋势、历史帧和使用边界。
- **预测时间轴详情**：按 10–60 分钟切换区域可能性与排序。
- **区域与回波对象详情**：选择样本区域，查看影响判断和相关回波对象。

## 运行

使用微信开发者工具导入本目录，选择“小程序”项目类型即可预览。数据集中在 `utils/mock.js`，页面分析由 `utils/analysis.js` 统一生成；接入实际观测或 AI 服务前，需要另行定义接口、更新时间与失败状态。

## 设计

视觉参考项目内的企智融 iOS 截图：浅灰底、白色内容组、蓝色主操作和悬浮胶囊导航，并保留气象结论与依据的清楚层级。
