# 云迹先知（CloudTrace）微信小程序 MVP

云迹先知面向“未来一小时强回波影响判断”：融合雷达回波、卫星云图、风暴对象移动趋势，输出区域级影响概率，并给出可追溯的判断依据。

## 目标场景

- **气象播报**：快速组织未来一小时趋势和重点区域
- **机场与交通调度**：关注跑道、进离港窗口和交通走廊
- **城市应急与防汛**：提前安排积水点、泵站和巡查力量
- **大型活动与园区防灾**：评估人群、户外作业和设施风险

## 页面

- **态势**：雷达 / 卫星融合图、未来一小时重点区域、场景切换
- **预测**：时间轴、区域风险排序、概率变化
- **区域**：区域影响详情、相关回波对象、进入影响窗口时间
- **依据**：雷达、卫星、移动趋势、历史帧一致性和推理链

## 运行

使用微信开发者工具导入本目录，选择“小程序”项目类型即可预览。当前数据为确定性本地合成演示，后续可将 `utils/mock.js` 替换为 `/v1/analyses` 请求层。

## 设计

视觉按 Apple Design 的原则重做：首屏优先任务结果、半透明层次、系统字体、即时反馈、克制动效和清晰的证据层级。

> 当前为 synthetic_demo 合成演示，不是实时预警。VIL 是强回波相关变量，不等同于降雨量或地面积水。
